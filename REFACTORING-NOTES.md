# Notes — технические изменения

## Что изменено
- Добавлен корневой `.gitignore` для `.vs`, `bin`, `obj` и временных файлов.
- Добавлен `Fix-GitTracking.ps1`: исключает уже отслеживаемые артефакты из индекса Git, не удаляя локальные файлы и не трогая исходники.
- Исправлено окно создания папки в Notes.Desktop: адаптивная высота, увеличенная ширина, Grid-разметка, перенос подсказки, корректные отступы и размеры кнопок.
- Добавлена иконка Notes (`src/Notes/Notes.Desktop/Assets/notes.ico`) и подключена к окнам входа, регистрации и главному окну.
- Добавлена настройка рамки/заголовка WPF-окон через Windows DWM: рамка использует системный акцентный цвет, цвет заголовка выбирается по системной светлой/тёмной теме; обновляется при изменении системных предпочтений.
- Все проекты из `src` включены в `AIC-Notes.slnx`, включая оба проекта Payments.
- WPF-клиенты больше не ссылаются напрямую на Web API как на исполняемый проект. Для платёжного модуля выделен отдельный `Payments.Contracts` с DTO, на который ссылаются и API, и Desktop.
- SQL и PostgreSQL-запросы Notes переведены со схемы `Ilgam` на разделение `auth`, `content`, `billing`.
- Единый SQL-шаблон создаёт новую структуру и переносит существующие таблицы из `Ilgam`, если они обнаружены.
- Webhook YooKassa сделан идемпотентным: повторное уведомление об уже оплаченной транзакции больше не возвращает 503 и не продлевает подписку повторно.

## Структура схем PostgreSQL
- `auth.Users` — учётные записи.
- `content.Folders`, `content.Notes` — пользовательский контент.
- `billing.UserAccess`, `billing.PaymentTransactions` — права доступа и платежи.

## Как обновить Git после клонирования
Из корня репозитория выполнить:
```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\Fix-GitTracking.ps1
```
Скрипт не удаляет файлы с диска. Он только исключает уже отслеживаемые генерируемые файлы из Git-индекса и добавляет `.gitignore`.

## SQL
Откройте `database/Database template.sql` в pgAdmin 4 Query Tool и выполните скрипт в нужной базе данных. Скрипт рассчитан на свежую базу и на перенос таблиц из старой схемы `Ilgam`.

## Проверка
XML-файлы XAML, csproj и slnx проверены на корректность структуры. Полная сборка `dotnet build` в среде подготовки не запускалась: .NET SDK здесь не установлен. Перед слиянием изменений выполните в Visual Studio:
```powershell
dotnet restore AIC-Notes.slnx
dotnet build AIC-Notes.slnx
```
